About This Catalog

This catalog is a live, client-side inventory demo for PrimeHaven. It includes product images hosted on reliable CDNs, stock tracking, quick sales recording, and a simple search and filter. Use the table to monitor stock and the sales tracker to simulate purchases. Data is stored in your browser localStorage so it persists between visits on the same device.

How tracking works

  • Stock decreases when a sale is recorded.
  • Sold increments to show cumulative units sold.
  • Summary updates automatically to reflect totals.

Next steps for production

  1. Connect to a backend API for persistent storage and multi-user access.
  2. Integrate payment gateways for live checkout (M-Pesa, Stripe, PayPal).
  3. Add charts and export options for market analysis.
